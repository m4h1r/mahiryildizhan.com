## Decisions (not touched — your call)

1. **E12 legal versioning.** The standard envisions a `legal_documents` /
   `legal_document_versions` table so a revision never overwrites text a customer
   already accepted. This site has no customer acceptance flow and you edit the legal
   Blade files yourself, so the full CMS is not worth it. Recommended minimum instead:
   show a "Son güncelleme / Last updated" date + version on each legal page, and
   (optionally) generate the retention sentence in `/kvkk` from `config/retention.php`
   so it can never drift. Both are in AUDIT_PLAN.md as quick items.

2. **E12 / İYS.** If the newsletter counts as *ticari elektronik ileti*, İYS
   registration is a legal requirement (not a template). If you treat it as a personal,
   non-commercial list, record that decision. Either way it belongs in
   `project-standards.md` — "not applicable, personal list" is also a recorded decision.
